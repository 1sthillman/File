- ✅ Kasa, adet, ek kg takibi
- ✅ Offline çalışma (internet gerektirmez)
- ✅ Sesli komutlar (Türkçe)
- ✅ Ürün görselleri ve kategoriler

### 🚚 Sevkiyat Yönetimi
- ✅ Palet bazlı sevkiyat
- ✅ Çoklu palet desteği
- ✅ Aranabilir ürün ekleme
- ✅ Miktarlı ekleme popup'ı
- ✅ PDF ve Excel rapor
- ✅ WhatsApp entegrasyonu

### 📊 Raporlama

## 🚀 Kurulum

### Android Cihaz
1. APK'yı indirin
2. "Bilinmeyen kaynaklardan yükleme" izni verin
3. APK'yı açıp yükleyin
4. Kamera izni verin (barkod okuma için)

### Gereksinimler
- Android 7.0+ (API 24)
- 100 MB boş alan
- Kamera (barkod okuma için)
- İsteğe bağlı: Zebra terminal

## 📸 Ekran Görüntüleri

### Sayım Ekranı
- Kompakt ürün kartları
- Kasa/Adet/Ek kg inputları
- Hızlı barkod okuma
- Sesli komut desteği

### Sevkiyat Ekranı
- Palet yönetimi (A, B, C, D...)
- Aranabilir ürün ekleme
- Sticky action bar
- Modern popup tasarımı

### Raporlar
- PDF: Palet ayrımıyla formatlanmış
- Excel: Detaylı veri tabloları
- WhatsApp: Hızlı paylaşım

## 🛠️ Teknolojiler

- **Frontend:** Vanilla JavaScript (PWA)
- **Backend:** IndexedDB + Firebase Realtime Database (opsiyonel)
- **Barkod:** OFFDEC (offline, 100% JavaScript)
- **PDF:** jsPDF
- **Excel:** Custom XLSX generator
- **QR:** QRC (embedded)
- **TTS:** Native Android TTS
- **Ses Tanıma:** Web Speech API
