# Manav Sayım Zebra v16 (File)

Bu proje Zebra el terminalleri ve barkod okuyucular için optimize edilmiş **Manav Sayım** web uygulamasıdır.

## 🌐 Canlı Demo / Yayın
GitHub Actions ve GitHub Pages ile otomatik olarak yayınlanmaktadır:
- **Canlı Adres:** [https://1sthillman.github.io/File/](https://1sthillman.github.io/File/)

## 🚀 Özellikler
- Zebra cihazları ile tam uyumlu barkod okuma ve sayım arayüzü
- Hızlı ve optimize veri girişi
- Otomatik GitHub Actions dağıtım iş akışı (CI/CD)

## 🛠️ GitHub Actions Dağıtımı
Herhangi bir değişiklik `main` dalına pushlandığında `.github/workflows/deploy.yml` tetiklenir ve GitHub Pages üzerine anında dağıtılır.
